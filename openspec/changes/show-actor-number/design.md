# Design

## Context

`--json` の `createdBy`・`updatedBy` は `{type, id}` で、dashboard が内部 ID で人を突き合わせる契約になっている。人向けの表示はその値をそのまま出していた。

## Goals / Non-Goals

**Goals:**

- 人向けの表示だけを、表示用の番号に変える

**Non-Goals:**

- `--json` に番号の項目を足すこと（必要になったら、項目の追加として `displayNumber` を足す）

## Decisions

### 番号は表示のときだけ引く

core の `ActorNumbers.of(db, actors)` で、表示する記録に出てくる人の番号をまとめて引く。`--json` のときは引かない。ユースケースが記録を返した後に、別の読み取りのトランザクションで引く。表示のための補助で、権限は記録を返したユースケースが確かめている。

- 管理者と会員の内部 ID は別の表の主キーなので、型と組で引く
- 引けない人は内部 ID で出す（管理者の表が無かった頃の記録、消えた行など）

## Risks / Trade-offs

- [記録を返した後に番号を引くので、その間に管理者が増えても表示は変わらない] → 番号は変わらないので、ずれは起きない
